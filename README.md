# Java WebSocket Chat

심심해서 이것저것 끄적이다가 갑자기 진행하게된

Java 기반 WebSocket 통신을 학습하기 위한 콘솔 채팅 프로젝트입니다.

동일한 Java 소스를 서로 다른 프로세스에서 서버 또는 클라이언트로 실행하며, WebSocket을 통한 실시간 메시지 송수신과 서버 측 연결 관리를 구현합니다.

Spring Framework와 Maven/Gradle을 사용하지 않고 Java 및 외부 JAR 라이브러리만으로 구성했습니다.

## 1. 기술 스택

| 구분 | 기술 |
|---|---|
| Language | Java 17 이상 |
| Communication | WebSocket (TCP 기반) |
| WebSocket Library | Java-WebSocket 1.6.0 |
| JSON Serialization | Gson 2.13.2 |
| Logging | SLF4J |
| Build | javac |
| Execution | Shell Script / JVM |
| Environment | Windows, WSL Ubuntu, Linux |

## 2. 프로젝트 구조

```text
my-dull-project/
├── lib/                  # 외부 JAR 라이브러리
└── src/
    ├── Main.java         # 서버/클라이언트 실행 분기
    ├── Server.java       # WebSocket 서버
    ├── Client.java       # WebSocket 클라이언트
    ├── MessageForm.java  # 송수신 메시지 DTO
    └── Chat.java         # 채팅 기록 객체
```

### 주요 클래스 역할

| 클래스 | 역할 |
|---|---|
| Main | 실행 인자에 따른 서버·클라이언트 구분 |
| Server | 접속 관리, 사용자 등록, 메시지 중계, 채팅 기록 |
| Client | 서버 연결, 사용자 입력, 메시지 송수신 |
| MessageForm | 메시지 유형 및 내용 전달 |
| Chat | 발신자, 메시지 내용, 전송 시간 기록 |

## 3. 시스템 구조

```text
               WebSocket Server
                127.0.0.1:8080
                       |
          +------------+------------+
          |            |            |
       Client A     Client B     Client C
          |            |            |
       Console      Console      Console
```

- 서버와 클라이언트는 각각 독립적인 Java 프로세스로 실행됩니다.
- 클라이언트는 서버와 WebSocket 연결을 유지합니다.
- 서버는 각 클라이언트의 WebSocket 연결 객체와 닉네임을 매핑합니다.
- 수신한 채팅 메시지를 서버 메모리에 기록합니다.
- 발신자를 제외한 다른 등록 클라이언트들에게 메시지를 전달합니다.

## 4. 현재 구현 기능

### 서버

- WebSocket 서버 실행 및 종료
- 클라이언트 연결 및 해제 감지
- 클라이언트별 닉네임 등록
- `ConcurrentHashMap` 기반 접속 사용자 관리
- JSON 메시지 수신 및 유형별 처리
- 발신자를 제외한 채팅 메시지 중계
- `ConcurrentLinkedQueue` 기반 채팅 기록 관리
- 채팅 기록의 발신자 및 수신 시각 저장

서버 콘솔 명령어:

| 명령어 | 기능 |
|---|---|
| `/clients` | 현재 등록된 클라이언트 조회 |
| `/chatLog` | 서버 메모리에 저장된 채팅 기록 조회 |
| `/exit` | 서버 종료 |

### 클라이언트

- 사용자 닉네임 입력
- WebSocket 서버 연결
- 연결 직후 `USER_JOIN` 메시지 자동 전송
- 채팅 메시지 송수신
- JSON 직렬화 및 역직렬화
- 서버 시스템 메시지 수신
- `/exit`을 통한 연결 종료

### 메시지 프로토콜

서버와 클라이언트는 JSON 문자열을 사용하여 데이터를 교환합니다.

```json
{
  "type": "CHAT",
  "content": "안녕하세요"
}
```

현재 정의된 메시지 유형:

| Type | 설명 |
|---|---|
| USER_JOIN | 클라이언트 사용자 등록 |
| CHAT | 일반 채팅 메시지 |
| SYSTEM | 서버 시스템 메시지 |

## 5. 실행 방법

외부 라이브러리 JAR 파일과 JDK가 준비되어 있어야 합니다.

프로젝트 루트에서 컴파일합니다.

```bash
mkdir -p out

javac -encoding UTF-8 -cp "lib/*" -d out src/*.java
```

서버 실행:

```bash
java -cp "out:lib/*" Main server
```

클라이언트 실행:

```bash
java -cp "out:lib/*" Main client
```

클라이언트는 여러 터미널에서 각각 실행할 수 있습니다.

위 명령어는 Linux 및 WSL 기준이며, Windows에서는 Classpath 구분자로 `:` 대신 `;`를 사용합니다.

현재 서버 접속 주소는 `127.0.0.1:8080`으로 고정되어 있어 동일 호스트 내부 통신을 기준으로 합니다.
